The flow

  1. 01 {{ partial "icon.html" "url" }}

    You enter a URL

    The audit form uses real HTML semantics and accessible validation. React lives only on this island.

  2. 02 {{ partial "icon.html" "document" }}

    Hugo serves the document

    Marketing pages ship as static HTML and CSS. The home page has no JavaScript.

  3. 03 {{ partial "icon.html" "island" }}

    An island mounts

    Audit, compare, result and dashboard hydrate from data-react-island. Everything else stays a document.

  4. 04 {{ partial "icon.html" "api" }}

    Go scores the URL

    The API validates the address, fetches the live HTML, and scores table-driven signals: HTTPS, TTFB, metadata, headings, alt text and labels.

  5. 05 {{ partial "icon.html" "ledger" }}

    The result is stored

    Recommendations come from a rule catalogue. The dashboard lists previous audits from a Repository — memory or SQLite.

What this demonstrates

  1. 01

    Static HTML first

    Documents are complete before JavaScript runs. Better for SEO, performance and noscript.

  2. 02

    React islands, not an SPA

    Interactive regions mount from a data attribute. The rest of the site does not wait on a bundle.

  3. 03

    Shared BEM

    Hugo templates and React components use the same class names. One design system, two renderers.

  4. 04

    A tiny Go API

    Clear package boundaries: validate, score, recommend, persist. The dashboard sits behind a password.
